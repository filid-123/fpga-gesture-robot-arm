# 以稳定夹取为目标的误差约定

2026-10-28用户明确允许“不影响夹取的微小误差”。后续不以追求零误差、重复测量或反复训练作为推进软件和目标机验证的前提。

当前候选保持，既有1–3 mm量级的尺寸/不同中心估计差异作为诊断记录，不直接判为失败，也不直接称其为已测实际抓取误差。尺寸差不等于中心位置偏移，同一静止摆放的重复性也不等于绝对精度。

实体器材可用时，红木块、橡皮、药瓶各做一次完整抓取核对作为第一轮：能在两爪间接近、物品没有明显被推开、夹起后停稳无滑落、放回时夹爪不碰桌面。通过后再按演示需要检查重复成功率；失败只针对实际影响夹取的方向/阶段修正，无需重测已确认的棋盘O/X。

不为三个物品设未经实测的统一“3 mm保证”。夹爪为一侧固定、一侧活动，现有固定爪相对物体余量是名义CAD参数，机械臂/TCP误差还会叠加；橡皮窄边需要重点观察。执行时应由实际可用间隙确定容许范围。

这项偏好用于后续工程验收，不翻转旧模型、相机、基座/TCP或实体完成标志，不修改现有运动模块。现在相机不可用，用户无需增加测量或摆放任务，先完成可离线推进的目标机交接。
