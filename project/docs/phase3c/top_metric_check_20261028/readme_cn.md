## 橡皮中心和尺寸差异

之前记录的橡皮像素中心来自四边形对角线交点。直接将这些旧像素中心投影，20帧最大平面距离约**2.84 mm**，Y方向范围2.78 mm，原13.05像素波动仍保留。

现有毫米几何使用四个角分别去畸变、投影后取平均，所得最大距离约0.53 mm。两种中心估计最大相差2.16 mm：对角线交点对窄长四边形的轻微梯形变化较敏感，四角均值更稳定不等于更准确。因此同时保存两组统计，**没有将原不稳定结果重写为已修复，也没有修改运行时算法或模型**。仍要用独立物理中心参考判断偏差。

红块投影尺寸比名义30 mm小约1.4—1.6 mm；橡皮长边比登记65 mm小约2.7 mm、短边比15 mm小约1.45 mm；药瓶比25 mm大约1.7—1.8 mm。误差方向不一致，不能统一乘一个比例当作修复。网络轮廓、打印/内参/外参、物品尺寸和物品姿态都可能贡献差异，目前没有足够物理证据分离原因。

药瓶圆心由**轮廓先去畸变、投影至46 mm平面，再拟合实体圆**取得；没有把图像椭圆中心直接当作实体圆心。直径差异仍需保留。
