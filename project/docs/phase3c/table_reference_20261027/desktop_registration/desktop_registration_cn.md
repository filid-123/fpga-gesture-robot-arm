## 文件与复现

- `DESKTOP_REGISTRATION_CANDIDATE.json`：二点来源、正反4×4变换、尺度/高度假设、原局部标定哈希。
- `RGB_DESKTOP_TRANSFORM_CANDIDATE.json`：`desk_global_mm`到相机的组合外参，直接兼容`RGBTableGeometry`的去畸变和已知高度投影。原局部候选保持原字节。
- `config/ai_pc/rgb_workspace_20261027_desktop_candidate.json`：绑定上述全桌外参哈希的新工作区候选，需要显式指定；旧默认、成功三色模型和六类profile没有更改。
- `COMPOSITION_CHECK.json`：0/15/30/46 mm高度的代数组合反投影自检。最大约3.46×10⁻¹³ mm只说明代码组合方向一致，不是实物定位精度。
- `pc/rgb_desktop_registration.py`和`scripts/register_rgb_desktop.py`：离线登记与组合工具，没有相机、网络、机械臂接口。几何函数支持平面旋转；当前CLI沿用轴对齐工作区绘图，旋转不为零时明确拒绝，避免绘制错误边框。
- 新增6项检查涵盖真实CLI图片导出、哈希绑定工作区、正反变换、旋转/高度、错误长度拒绝、帧名与原文件保护；既有4项棋盘/直尺检查也通过。没有改运动模块。
