# 联测硬件与现场验证

p4 先确认 `native_giao_full_workspace_p4` 和同包 ABI340E 位流。无 RGB、无物品或部分物品可见时，空 HOME 仍可锁定 B；只有数字启动的所选物品才要求新鲜视觉和路径。三类中心边界 X490～690、Y215～355 mm，历史锚点半径已取消；机械/碰撞/形状约束保留。B 按 Giao 分段速度与行程公式夹爪等待，A 保持原速度。首次新动作需人员观察夹持和退出，公共点补回保持独立策略。A↔B 采用固定空 HOME 过渡，记录实际切换和规划/传输耗时。

本版新增 FPGA 内部路径播放器和匹配 BIT，不改现场供电、固件、扭矩或传感器安装。现有实测连接保持：PYNQ-Z2 PMOD D1 / U12 TX → RoARM TTL RX，D0 / T14 RX ← RoARM TTL TX，共地，已验证 3.3 V 逻辑；D5 / T15 为既有 3.3 V 许可，程序启动前接好，运行中保持。不是把机械臂供电接到 GPIO。机械臂继续用原电源，PYNQ 用原电源和 JTAG，OV5640、HDMI OUT 保留原接法；普通 RGB 通过 AI PC 的 USB 接口连接。

断电后才能调整接线。沿用现场现成的停止/断电手段，D5 与 FIST 的区别见主手册；本版不把 FIST 宣称为急停。第一次运行必须空夹爪、已知 HOME、清空运动区域、三槽按原位放物。移除 B 旧承托台；公共点每次只放本次选择的一个物品。
