# 接口定义与异常处理

正式寄存器/报文说明见 [原接口文档](../project/docs/mode_ab/interface.md) 和 [p4 轨迹合同](../project/docs/mode_ab/native_routes_p4.md)。本页是比赛入口，不另造第二套寄存器规范。

| 窗口 | 地址 | 用途 |
|---|---|---|
| B 路径 RAM | 0x43C20000 | 原生采样与阶段描述符，ABI B001 |
| 机械臂后端 | 0x43C30000 | 原生 TTL 格式、反馈与配置 |
| 规划/执行 | 0x43C40000 | 实时轨迹底座 |
| 任务/控制权 | 0x43C50000 | A/B 任务，TASK ABI 340E |
| PL 视觉 | 0x43C60000 | OV5640 与手势状态 |

p4.1 修复 XSDB loadhw 漏注册的 0x43C20000～0x43C20FFF，并在 JTAG_READY 前检查 B001；修复未改变 BIT/HWH/XSA。三项启动映射离线测试为原封包证据；2026-11-01 新增用户实测验收确认 p4.1 已能完成现场任务。启动可用和现场恢复问题分别记录，两次任务完成后发生的 JTAG Invalid context / 恢复未确认仍 OPEN。

B 路径使用六轴 Q16 数据，六个 2048×18 位真双口 BRAM 和六个 32 位基准恢复原值；192 字描述符记录三档/16 阶段的地址、数量、周期及正反向速度。仅在 B WAIT_PATH 静止上传，每字回读后 COMMIT；原生格式要求 flags[7]=1、profile=0。开始、提交、运行和暂停有写锁。

Web 仅监听 127.0.0.1，配置请求带会话 token、同源检查、request_id 和 expected_revision。真实任务由 PL 数字手势启动；没有网页直接抓取按钮。任务完成计数和物理抓取成功分开记录。

反馈新鲜度、下游阻塞、D5 和原故障策略保持原合同；原 UART 间歇问题 OPEN。现已从52,884次实际RPC复算RTT和2次命令异常（0.003781862%），端点为Python调用至XSDB/JTAG/PL AXI回复，详见[复算口径](metrics_recovery_20261101.md)。包含失败的最大耗时5551.759ms，成功调用最大786.7561ms。物理响应另有用户视频人工计时620ms（手势已入镜→首次可见运动），见视频计时复核单；单向通信及物理响应分布仍需对应计时序列。离线规划耗时及理论带宽不能替代。
